# Worked Examples and Workflow Exercises

The examples in this directory demonstrate how to use the documents. They are **not completed contest solutions**. The campsite fixture below has actually executed synthetic calculations; other exercises are labeled prospective protocols, not invented results.

A separate [executed 2022 HiMCM B rehearsal](../../HIMCM_Rehearsals/2022_HiMCM_B_2026-11-03/README.md) now contains an actual historical-problem analysis, agent handoffs, adversarial attacks, repaired implementation and file-based recovery. Its own delivery and review records govern the complete-paper export; it does not retroactively turn the illustrative exercises below into executed solutions.

- [Approach-defense walkthrough](APPROACH_DEFENSE_WALKTHROUGH.md): prompt-to-model reasoning, baseline, exact tiny-instance comparison, rejection checks, roles and bounded justification. Includes [runnable artifacts](approach_demo/README.md) and an [independent review](../qa/APPROACH_DEMO_REVIEW.md).
- [Multi-agent handoff walkthrough](MULTI_AGENT_HANDOFF_WALKTHROUGH.md): a synthetic school-equipment budget project with assignments, handoffs, receipt acknowledgments, review loops and stale-dependency recovery.

- [Forecasting exercise](FORECASTING_WALKTHROUGH.md): requirements, model choice, validation and rejection for a time-series problem.
- [Planning exercise](PLANNING_WALKTHROUGH.md): coupled accounting and discrete decisions, feasibility, handoffs and bounded recommendations.
- [Failure and recovery exercises](FAILURE_EXERCISES.md): file conflicts, stale results, missing data, interrupted sessions and unsupported claims.

Historical anchors are identified explicitly. Exercise decisions illustrate the workflow; they are not attributed to a historical team unless a review says so. A paper comparison is different from a blinded, independently executed modeling trial. No claim is made here that the workflow has already solved either historical problem numerically.
