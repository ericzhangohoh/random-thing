## Computation request M06 — accepted clarification

A first annual crossing is an event established from a valid contiguous prefix. A later invalid segment cannot retroactively delete that event. Thus preserve CROSSED and the first year, but mark `search_domain_valid=false` with exact `invalid_from_year`, reason and prefix endpoint. The paper must show the warning. This does not certify full-path plausibility.

If origin or a required year before/at the apparent crossing is invalid, first passage cannot be established across the gap: INVALID_PATH with first_year=null. Do not skip the failure or resume at a later valid value. A valid already-above origin remains AT_OR_BEFORE_ORIGIN with any later warning. Only a fully valid subthreshold domain returns NO_CROSSING_THROUGH_2300. Required inputs are checked before same-year threshold comparisons. Negative temperature anomalies remain valid; nonpositive CO2 is invalid.

Full r02 spec/interface now define this precedence, fields, numerical tolerance, diagnostic domain and test cases. This clarifies r01's ambiguous failure handling without altering any fitted function, training rows, forecast number, selector, threshold or search horizon.
