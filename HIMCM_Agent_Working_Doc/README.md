# HiMCM Multi-Agent Working Document

An English operating document for a human-led modeling team, with six assignable Claude Code roles and an inspectable historical research base.

## Start

1. Read [WORKING_DOC.md](WORKING_DOC.md) for the full process and human decision checkpoints.
2. Read [Approach and Justification](APPROACH_AND_JUSTIFICATION.md) for the reasoning behind model selection, validation and defensible claims.
3. Use [Claude Code setup](setup/CLAUDE_CODE.md), [the bootstrap prompt](setup/BOOTSTRAP_PROMPT.md) and [role instructions](roles/README.md) to assign real sessions.
4. Use [templates](templates/README.md) and [coordination](COORDINATION.md) for tasks, evidence, handoffs and recovery.
5. Inspect [worked exercises](examples/README.md), [research coverage](research/STATUS.md) and [verification limits](qa/VERIFICATION.md).

The original MCM/ICM collection is the primary research source. **Full-corpus reading remains in progress** and is tracked per paper; the operational document must not be described as a completed synthesis of every paper yet.

The complete substantive project is stored in the owner's [private repository](https://github.com/ericzhangohoh/himcm). Original papers and source bytes are retained. Native Claude role files are optional, inert templates; no software installation or global configuration change is required to read and use the manual-session workflow.
