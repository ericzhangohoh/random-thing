# HiMCM Multi-Agent Working Document

An English operating document for a human-led modeling team, with six assignable Claude Code roles and an inspectable historical research base.

## Start

1. Start with [Execution Playbook](EXECUTION_PLAYBOOK.md) for first assignments, dependencies and handoffs; use [WORKING_DOC.md](WORKING_DOC.md) for the full process and human checkpoints.
2. Read [Approach and Justification](APPROACH_AND_JUSTIFICATION.md) for the reasoning behind model selection, validation and defensible claims.
3. Use [Claude Code setup](setup/CLAUDE_CODE.md), [the bootstrap prompt](setup/BOOTSTRAP_PROMPT.md) and [role instructions](roles/README.md) to assign real sessions.
4. Use [templates](templates/README.md) and [coordination](COORDINATION.md) for tasks, evidence, handoffs and recovery.
5. Inspect [worked exercises](examples/README.md), [research coverage](research/STATUS.md) and [verification limits](qa/VERIFICATION.md).

Two fresh-context GPT-6 Astra reviewers audited the workflow on 2026-11-03. After author repairs and independent re-review, the [workflow audit](qa/ASTRA_AUDIT_2026-11-03.md) and [cold-start contract audit](qa/ASTRA_COLD_START_AUDIT_2026-11-03.md) returned **ACCEPTED_FOR_SCOPE**. The evidence covers the written process, eight synthetic numerical scenarios, and an isolated source-recovery check. Actual Claude multi-session orchestration and a complete contest-paper export have not been tested. Follow the pinned versions and scope in the reports.

The original MCM/ICM collection is the primary research archive. **All biology-related papers are excluded from further research by the user's instruction.** The [scope record](research/SCOPE.md) supersedes the earlier all-paper plan. Coverage remains explicit; this document does not claim that every archived paper has been reviewed. Non-biological research supports the workflow without making exhaustive archive reading a prerequisite for using it.

The complete substantive project is stored in the owner's [private repository](https://github.com/ericzhangohoh/himcm). Original papers and source bytes are retained. Native Claude role files are optional, inert templates; no software installation or global configuration change is required to read and use the manual-session workflow.
