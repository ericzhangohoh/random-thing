## Demand map and architecture

The paired official problem asks for an objective specification ranking, top ten, comparison with two external lists, a conceptual app and one-page news release. This paper supplies a general ranking, extends comparison to twenty coasters, constructs a personalized variant, and connects both directly to app flows. Its news release appears on p.27. The main scope is the supplied dataset, reduced from 300 to 299 after excluding a recent ride whose characteristics are largely missing (p.6).

The pipeline is:

`Raw data and coverage audit → regression-variable selection → dependency-ordered imputation → standardized feature groups → general weighted score and material adjustment → rank comparison and perturbations → AHP-derived user weights → same scoring engine → two app journeys.`

The general and personalized methods share a computation instead of duplicating nearly identical models. The personalization layer changes only the group weights, while geographic/type filters narrow the candidate set (pp.22–31).

## Explicit approach rationale

The introduction distinguishes casual users who want an immediate default ranking from enthusiasts willing to specify preferences (pp.5–6). This requirement drives both the mathematics and the interface. Grouping eight specifications into three categories reduces the number of pairwise preference questions from 28 to three (p.22). The explicit count connects a mathematical simplification to usability.

The imputation sequence is also justified concretely. Speed depends on height; drop needs completed speed; length and duration appear to depend on one another, but the four records missing length already have duration. Thus length can be filled before completing duration (pp.8–9). The resulting order is speed → length → drop → duration → G-force → vertical angle. This is dependency analysis at the row level, rather than a generic instruction to fill missing cells.

The authors group speed/drop/height as thrill, angle/G-force/length/duration as fundamentals, and inversion count as a separate dimension, using observed regressions and correlations as motivation (pp.11–12). The redundant inversion indicator is excluded. Year is excluded because maintained ride quality is not inherently determined by age; type is reserved for personal preferences; material gets a separate adjustment (p.12). Features are standardized and each group's weight is divided by its number of features so groups with more indicators do not automatically receive more total weight (pp.13–14).

**Reviewer inference:** the workflow should reuse this dependency-first reasoning and explicit reduction of user burden. However, correlated variables do not automatically measure the same latent construct, and relations strengthened by imputation are not independent evidence for the grouping. The three categories still embody interpretation.

## Data, assumptions and parameters

Regression covariates are retained using a 5% significance threshold, with one worked elimination sequence and a compact table of final predictors and R-squared values (pp.8–9). The lowest reported R-squared is 0.233 for vertical angle; G-force is 0.477. These are described more optimistically than the evidence warrants. Linear imputation and representativeness are explicit assumptions (p.7), but the official dataset was intentionally selected for above-average specifications, so representativeness of all coasters cannot simply be assumed.

The general weights are 5:5:1 across thrill, fundamentals and inversions (p.13). They are assigned judgments, not estimates from a measured response variable. The paper sometimes calls the scoring equation a regression; it is an assumed additive rating model. The material correction uses regression-estimated differences of 26.2 seconds in duration and 0.7620 in G-force, subtracting the corresponding standardized adjustment from steel coasters (p.14). Conditional association alone does not prove a causal construction effect or that this correction defines fair comparison.

The linear-benefit assumption is unusually explicit: equal increases in length have equal benefit; the authors acknowledge that G-force and angle might require saturation (p.15). The implausible 2G ceiling stated later conflicts with their own mean G-force of 4.18 (pp.13, 21); it should not be transferred as physiological guidance.

## Validation and supportable claims

Before/after correlation plots provide a useful structural check (pp.10–11). The plotted variables exclude G-force and vertical angle, the most heavily missing fields, and visual similarity of correlation matrices is not a predictive holdout test. Reported training fit and significance do not establish out-of-sample accuracy or uncertainty of imputed cells. Comparing training R-squared against the zero R-squared of mean prediction is a weak benchmark without held-out errors.

External comparisons identify seven overlapping North American leaders with Coasterbuzz and eight of twenty with an expert list, alongside geographic explanations (pp.16–18). These demonstrate some agreement while leaving the causes of disagreements untested. They do not establish population preference recovery from physical attributes.

Three separate group-weight perturbations retain the top four and introduce at most one new top-twenty entrant (pp.18–20). This supports local stability under those specific tested changes. The prose says both “increase by 0.1” and “10%,” which differ for coefficients 5/3 and 5/4. Neither parameter decreases, data-imputation uncertainty nor alternative material corrections are explored. The personalized example uses a much larger preference change and alters membership substantially (pp.24–26), usefully showing that local robustness does not imply invariance across user goals.

## Static implementation checks

The appendix is not a clean executable reproduction of the complete method. The drop model in code uses speed alone rather than speed and height, the duration model uses ratios absent from the final predictor table, and intermediate fixed/full CSV files are assumed to exist (pp.34–36). The script replaces entire G-force and angle columns with predictions, rather than only missing entries, so observed values would be overwritten in that displayed step (p.35).

For the personalized example, the appendix initializes `weights` to already divided feature coefficients, then divides the first two entries again when constructing `coefs` (pp.36–37). This differs from the once-only group-size adjustment in the derivation (pp.23–25). A tiny hand-computed example would detect the discrepancy. The material correction must be checked against whichever group or per-feature coefficient is actually stored.

The interpretation labels heights of 420 and 171 as meters, whereas the original height field is in feet (pp.25–26). The summary refers once to four groups although the body uses three, and the release signs a different team number (pp.1, 27). These are presentation integration errors, not independently reproduced ranking errors.

## Transfer to the working document

Have the data engineer draw an imputation dependency graph and check whether dependencies are available for each missing row. Preserve observed values and tag every imputation. Require stored out-of-sample residuals before calling imputation accurate. Let the modeler define group totals separately from per-feature coefficients and prove the scaling convention once. Have the validator check uncertain and inconsistent AHP inputs even if the model depends on user choices; the paper's decision to omit personalized-model tests is not a general exemption. Use the same engine for general and personal scenarios, and show a complete three-question-to-ranking example in both the document and app concept.
