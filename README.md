# Mathematical Modeling Preparation and Agent Workflow

Private working repository for HiMCM preparation, historical modeling research and an English multi-agent working document.

## Start here

- [Agent working document](HIMCM_Agent_Working_Doc/WORKING_DOC.md): the operating procedure from problem intake to an evidence-backed solution.
- [Research status](HIMCM_Agent_Working_Doc/research/STATUS.md): actual full-paper review coverage and remaining work. Extraction is not review.
- [Original MCM/ICM collection](MCM-ICM-master/README.md): the primary research collection supplied by the user.
- [Additional HiMCM materials](HIMCM_备赛资料/00_开始阅读.md): official problems, commentary, papers, textbooks and source records.

The working document is being implemented and the complete historical-paper review is in progress. Do not interpret a committed source file or an automatically extracted text as a completed scholarly review.

## Repository contents

The original collections are retained in their existing folders. The user has chosen to store the full substantive project in a private GitHub repository, including source PDFs. Operating-system metadata, temporary render images and interpreter caches are excluded. Original source notices, licenses and provenance remain attached to their respective materials; repository privacy does not change those terms.

The original MCM/ICM archive includes problem statements, award lists, commentary and papers of several stated award levels. File and folder names sometimes disagree with document contents. The research inventory records these discrepancies rather than treating every PDF as an O-award paper.

## Collaboration

Read the working document and your assigned role before making changes. Use one current writer per file and explicit task handoffs. This preparation repository is not itself an authorization to submit competition work or to invite outside collaborators to a live contest project.

No paid automation, public site, GitHub Pages deployment or unattended agent execution is enabled by this repository.
